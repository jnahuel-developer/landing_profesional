# Producción

La topología productiva está decidida y documentada en `docs/operations/`, pero su implementación queda diferida.

No se incorporan todavía Caddy, imágenes Docker productivas, GHCR, scripts de despliegue, timers, backups automáticos ni monitoreo externo. Su introducción deberá respetar los ADR-013 a ADR-017.
