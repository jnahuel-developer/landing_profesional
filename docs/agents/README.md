# Operación de agentes

Esta carpeta define cómo se encargan, ejecutan, validan y corrigen las mods desarrolladas con Codex.

- [Operación y control](OPERACION_Y_CONTROL.md): responsabilidades, ciclo de trabajo, commits y puertas de calidad.
- [Plantilla de encargo](PLANTILLA_ENCARGO_MOD.md): estructura que se completa para iniciar una mod.
- [Plantilla de corrección](PLANTILLA_CORRECCION.md): estructura para resolver fallos locales o de GitHub Actions.
- [Checklist de validación](CHECKLIST_VALIDACION.md): controles posteriores a la ejecución del agente.

Las reglas obligatorias que Codex recibe automáticamente se encuentran en [`AGENTS.md`](../../AGENTS.md). Los documentos de esta carpeta explican el procedimiento; no reemplazan el alcance particular de cada `MODxxx.md`.
